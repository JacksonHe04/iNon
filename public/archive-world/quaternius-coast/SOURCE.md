# Quaternius coastal wildlife

The original GLB models in this directory are published by Quaternius through
Poly Pizza under the CC0 1.0 Universal license.

- `ButterflyFish.glb` — Butterfly Fish, https://poly.pizza/m/s2MkBeSzGy
- `Crab.glb` — Crab Enemy, https://poly.pizza/m/Gs3yfsV5lB

Both files retain their authored meshes, skins, materials, and animation clips.
The butterfly fish uses `Swimming_Normal`; the crab uses `Walk`. Runtime code
only determines their player-relative paths, shoreline height, and faded scene
tone.
