# 唯一主屋生活圈空间逻辑

## 问题

场景实际只有 `single-coastal-archive-home` 一座主屋，但旧庭院用 62 段等距木栅栏围成完整矩形，花园、泳池、火塘与工作台又分别贴着边界排列。建筑数量虽然已经收束，空间仍会被读成封闭、规则的陈列院或庙宇群，而不是一处自然生长的海边住家。

## 改造

- 完整矩形围栏改为 20 段轻微错位的局部围栏，只服务工作院、花圃和泳池安全边；主路径、海岸方向与大部分林缘完全敞开。
- 入口石径继续作为唯一主轴，西侧组织真实工作院，东侧保留花园和泳池，火塘与柴垛面向海岸，所有生活功能都能从主屋步行抵达。
- 工作院复用现有 Quaternius GLTF：工作台、抽屉工作台、木桶、水桶、绳索、木箱与运货车；门廊补入长凳、行李、木箱和灯具，没有程序生成的可见道具。
- 六棵 CommonTree / TwistedTree 真实树木重新把森林引到 34 米清场边缘，每棵树同步加入 Rapier 圆柱碰撞；玩家能看到林缘侵入，也不能直接穿过树干。
- 花园补入金属水桶与行李，既有泳池、花朵、篝火、柴堆、收藏展示和主屋室内均保留。

## 浏览器验收

- `http://localhost:3000/` 在内置浏览器冷启动后显示 `WebGL live`；出生相机为 `-13.0 / 2.7 / 32.0`，场景只出现一座带门窗的临海主屋。
- 修改后截图能够同时看到主屋、开放海岸、山坡、外围树林、石径、泳池与生活道具；围栏不再四面封闭，也没有新增第二栋房屋或寺庙式建筑。
- 页面运行状态为 `303 draw calls / 1,226,880 triangles / 33 scene nodes`，记录为后续性能优化的第一份可比较基线。
- TypeScript 与差异检查通过；三个相关源码文件分别为 160、126、35 行，均低于 300 行。

## 不变项

本阶段没有修改音乐与影视收藏数据、卡片检视、AI 对话、动物目录、无限地形、天气或第一人称控制。
