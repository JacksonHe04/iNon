# 性能优化第九阶段：首屏运行成本与庭院资产

日期：2026-08-04

## 目标

在不削弱开放世界生命感、主屋辨识度和庭院细节的前提下，继续降低出生点的常驻 CPU、GPU 与模型请求成本。音乐收藏和影视收藏未改动。

## 浏览器对照

所有数据均来自 `http://localhost:3000/` 内置浏览器的冷进入世界模式，并在资源稳定后读取场景诊断。

| 指标 | 原始基线 | 第八阶段结束 | 第九阶段结束 |
| --- | ---: | ---: | ---: |
| Draw calls | 320 | 174 | 159 |
| Triangles | 1,247,813 | 640,934 | 591,069 |
| Scene nodes | 33 | 31 | 31 |

相对原始基线：

- Draw calls 减少 161，约 50.3%。
- Triangles 减少 656,744，约 52.6%。
- 渲染像素相对最初 1.50 DPR 减少约 19%。

相对第八阶段结束：

- Draw calls 再减少 15，约 8.6%。
- Triangles 再减少 49,865，约 7.8%。

## 本阶段实施

### 1. 环境判定降频

- 野生动物不再由每只动物、每一帧重复计算玩家地形与生态区。
- 生态区流式判定每 12 帧采样一次。
- 收藏品靠近检测每 10 帧采样一次。
- 收藏半径、触发结果和动物移动仍保持原行为。

浏览器验证：伙伴状态可从 `resting` 正常切换为 `following`，WebGL 无错误。

### 2. 骨骼动画统一为 30 Hz

新增共享的动画推进器，覆盖：

- 普通野生动物；
- 伙伴犬；
- 坐骑；
- 使用统一动物场景封装的水生动物。

位置更新、导航、碰撞和交互仍逐渲染帧执行，仅骨骼 Mixer 使用 30 Hz 累积采样。长帧补偿被限制在 100 ms 内，避免切回标签页后突跳。

### 3. 远圈森林与地表密度

- 海岸/草甸树木中圈每块由 8 降为 7，外圈由 3 降为 2。
- 海岸/草甸/湿地地表中圈每块由 32 降为 28，外圈由 16 降为 12。
- 玩家所在块与近圈保持完整密度。

冷重载截图确认主屋周围仍有完整树群轮廓、前景植物、石块和枝叶层次。

### 4. 庭院石径低面数实例化

原石径使用五份独立高面数模型：

- 三种小石；
- 门槛薄石；
- 门口宽石。

它们被替换为三组低面数不规则石块实例，同时保留原始错位坐标、旋转和三档大小。

结果：

- 主屋庭院约从 133k 降到 112k triangles；
- 总场景约减少 21k triangles；
- Draw calls 减少 3；
- 冷进入不再需要五个 RockPath 模型；
- 浏览器截图中踏脚石路线仍连续、自然且清晰。

### 5. 被遮挡后院按需加载

出生点位于房屋正面，后院工坊被主屋完全遮挡。现在：

- 距后院中心 28 米内才挂载工坊资产；
- 挂载后使用 38 米退出半径，避免边界抖动；
- 花园、泳池、火堆、石径、围栏和门廊始终保留。

内置浏览器验证：

1. 出生点稳定诊断为 159 draw calls、591,069 triangles。
2. 长按前进，摄像机由 `Z 32.0` 到 `Z 22.8`。
3. 进入加载半径后，工坊恢复；同时主屋室内按既有距离机制挂载。

## 视觉验收

- 主屋依旧是唯一视觉主体，没有新增成排房屋或碑状标牌。
- 出生点仍可见动物、伙伴、山坡、树群、泳池、花园、火堆和石径。
- 纸屑天气、褪色灰绿、深森林绿、旧纸与颗粒氛围未削弱。
- 石径从资产堆砌变成更清晰的错落构图，方向感更强。
- 本阶段未触碰音乐收藏与影视收藏卡片。
